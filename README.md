Welcome to **Java OOP Basics to Advanced**!

This repository documents my journey of learning Java programming, starting with the fundamentals and progressing to advanced Object-Oriented Programming (OOP), software design principles, and real-world application development.

My goal is to develop strong Java programming skills through practical examples, exercises, projects, and consistent practice.

## 💻 How to Run Java Programs

Check Java installation:

```bash
java -version
javac -version
```

Compile a Java program:

```bash
javac Main.java
```

Run the program:

```bash
java Main
```
